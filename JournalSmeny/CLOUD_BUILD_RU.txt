ОБЛАЧНАЯ СБОРКА APK — ЖУРНАЛ СМЕНЫ

1. Распакуйте архив на компьютере.
2. Откройте папку JournalSmeny внутри распакованного архива.
3. В GitHub откройте ваш репозиторий. Если он пустой, нажмите ссылку Uploading an existing file.
4. Загрузите содержимое папки JournalSmeny: папку app, файлы build.gradle.kts, settings.gradle.kts, gradle.properties и текстовые файлы.
5. ВАЖНО: в архиве есть папка .github/workflows/android.yml. Она нужна для автоматической сборки. Если папка .github не отображается или не загружается через веб-форму, откройте файл GITHUB_WORKFLOW_COPY.txt и следуйте инструкции в начале файла: создайте на GitHub файл с путём .github/workflows/android.yml и вставьте содержимое из этого текстового файла.
6. Нажмите Commit changes.
7. Откройте вкладку Actions. Если GitHub предложит включить Actions, подтвердите. При загрузке проекта workflow должен запускаться автоматически.
8. Дождитесь завершения Build Android APK. Зелёная галочка означает, что сборка завершилась успешно.
9. Откройте запуск сборки, найдите раздел Artifacts и скачайте JournalSmeny-APK.
10. Распакуйте скачанный artifact ZIP. Внутри должен быть app-debug.apk. Передайте его на телефон и откройте для установки.

Примечание: этот архив содержит исходный проект и настройки облачной сборки, но не готовый APK. Сам APK появится после успешной сборки GitHub Actions.
