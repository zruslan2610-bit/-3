ЖУРНАЛ СМЕНЫ — Android-проект

Функции:
- Начальный остаток бункера № 1 (тонны)
- Начальный остаток бункера № 2 (тонны)
- Начальный остаток силиконового масла (литры)
- Поступление и расход за смену для каждой ёмкости
- Автоматический расчёт конечных остатков
- Автоматическая сумма двух бункеров в начале и конце смены
- Никакие данные не сохраняются; после закрытия приложения введённые значения пропадут

Как получить APK:
1. Установите Android Studio на компьютер.
2. Откройте в Android Studio папку JournalSmeny.
3. Дождитесь синхронизации Gradle и установки нужных компонентов Android SDK.
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK обычно будет в app/build/outputs/apk/debug/app-debug.apk.

Проект использует Android Gradle Plugin 8.7.3, Kotlin 2.0.21, compileSdk 35.
